## About Project

Based on RyiSnow's game engine tutorial, this repository contains the code for a custom RPG game focused on teaching introductory Java coding skills to players.
> ⚠️ **Note:** This project is currently a work in progress.


## Built With

*   **Language:** Java
*   **IDE:** IntelliJ IDEA

## Quick Start

1. Clone the repository.
2. Open the project folder in IntelliJ.
3. Run the main class file to start the game
